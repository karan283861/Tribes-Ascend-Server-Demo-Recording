# Tribes-Ascend-Server-Demo-Recording

## Cloning

> git clone git@github.com:karan283861/Tribes-Ascend-Server-Demo-Recording.git --recurse-submodules

## CMake generation

> cmake -S . -B x86 -A Win32 -T v142

## Building

> cmake --build x86 --config=RelWithDebInfo

## Requirements
1. Microsoft Visual C++ Redistributable 2019 (x86)

## Usage
- Demo recording begins on match start
- Demo files are saved under C:\Users\User\Documents\My Games\Tribes Ascend\TribesGame\Demos
